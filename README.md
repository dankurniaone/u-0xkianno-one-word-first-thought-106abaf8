# One Word, First Thought

One original word — the first that comes to mind — written for the [One Word, First Thought](https://make.fun/competitions/u-0xkianno-one-word-first-thought-106abaf8) bounty on [make.fun](https://make.fun).

## The word

> **syzygy**

The alignment of three celestial bodies in a straight line. Three y's, no other vowel in sight — a word you would never guess, that calls up a clear image (planets lining up), and rewards a second look. Surprising, vivid, and chosen, not filler.

## Run it

```sh
npx tsx main.ts
```

`main.ts` validates the gate (exactly one word, 1–24 characters, letters only) and writes the word to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable).
